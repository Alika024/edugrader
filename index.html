Project Background & Objectives

Subjective examinations are essential for evaluating students' deep comprehension, reasoning, and synthesis capabilities. However, manually grading descriptive essays and answers is highly labor-intensive, time-consuming, and prone to grading bias or fatigue.

EduGrade AI solves this challenge by acting as an intelligent co-pilot for teachers. Using advanced generative AI combined with semantic local analysis, it interprets the subjective context, compares it to the teacher's benchmark (model answer), and returns consistent, unbiased marks alongside comprehensive learning feedback.

Our Core Philosophy

  • AI-Assisted, Not Replaced: The AutoGrader works to augment teachers, providing instant second opinions and draft feedback.
  • Semantic Relevance: Evaluates the core concepts rather than just matching characters or syntax.
  • Pedagogical Feedback: Places more value on actionable student growth than numerical scores.

Grading Process Pipeline

1

Input Submission

Student answers and the teacher's model answer are uploaded or typed into the system along with rubrics details.

2

NLP Preprocessing & Feature Extraction

Counts words, characters, estimate reading times, and runs local token matching to assess text length, keyword hits and richness.

3

Contextual AI Semantic Evaluation

The core evaluation prompt is routed to Gemini API (or the local rules engine fallback) which examines definitions, context, and structural coherence.

4

Grading Output & Logging

The system normalizes scores, computes confidence scales, updates the dashboard analytics, and populates the printable PDF report.

Assessment Guidelines

To obtain highly accurate grading scores from the engine, follow these recommendations:

  • Provide at least 3-4 sentence structures in the Model Answer with specific key terms.
  • If you are in Local Mode, the matching accuracy relies strongly on keyword overlaps between the two answers.
  • For grading in languages other than English or deep logical validation, switch to Gemini AI Mode.

Gemini API Configuration

Enter your Gemini API Key to connect this web application directly to the live Google AI Cloud evaluation engine. This allows the AutoGrader to execute dynamic subjective logic, detailed text analysis, and premium teacher feedback creation.

Your API Key is kept 100% locally in your secure browser's local storage and is never uploaded to any remote server (except direct API requests to Google).

How to get a free API Key?

  1. Visit the Google AI Studio portal.
  2. Log in with your Google account.
  3. Click on "Get API Key" on the side menu.
  4. Create a key, copy it, and paste it here!
